# Evaluation outputs

The integrated pipeline will generate metrics.json and historical diagnostic predictions.csv.
Record per-asset average_precision, equal-weight macro AP, same-row benchmark and the relative quality gate.
Keep symbol and UTC timing identifiers so predictions can be traced to source candles.
The probability field is an uncalibrated score; estimator-default binary predictions are not an approved alert policy.
The final period has prior analytical exposure. Report actual runs and limitations, never assumed results.
Generated reports are ignored by Git; this README may be tracked.
